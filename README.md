# YMusic Discord RPC

Отображение текущего трека из Яндекс Музыки в статусе Discord (Rich Presence) с поддержкой обложек, контролем приватности и AMOLED-интерфейсом.
Работает в Windows 10 и 11 через системный механизм **Windows SMTC** (*System Media Transport Controls*). Отслеживает воспроизведение как в официальном десктопном приложении, так и в браузерах.

---

## Возможности

- **Адаптивный AMOLED-интерфейс**: глубокий чёрный фон (`#000000`) с мягким динамическим неоновым свечением под цвет текущей обложки.
- **Отображение обложек**: автоматический поиск и передача официальных постеров альбомов и треков в статус Discord.
- **Управление статусом**: тумблер в один клик отключает или возобновляет трансляцию в Discord (при отключении статус в профиле мгновенно очищается).
- **Автозапуск вместе с системой**: настройка автостарта через реестр (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) без запросов прав администратора; запуск происходит сразу в свёрнутом виде.
- **Проверка региона и защита от блокировок**: определение страны IP-адреса. При обнаружении зарубежного IP интерфейс подскажет о раздельном туннелировании (для предотвращения ошибки 451 со стороны Яндекса).
- **Приватность IP**: клик по плашке IP скрывает или открывает адрес, защищая от случайной демонстрации на стримах и скриншотах.
- **Журнал событий (Логи)**: плавная раскрывающаяся панель с автопрокруткой и возможностью сохранить последние 150 строк в файл на Рабочий стол (`ymusic_rpc_logs.txt`).
- **Фоновая работа в трее**: при закрытии окно сворачивается в область уведомлений Windows рядом с часами.
- **Защита от повторного запуска**: единичный экземпляр программы (Single Instance) через локальный IPC-сервер — повторный запуск активирует и разворачивает уже открытое окно.

## Быстрый запуск (Готовый .exe)

Скачайте файл `YMusicRPC.exe` из раздела [Releases](https://github.com/DilanBlue/YMusicRPC/releases) и запустите:
```cmd
YMusicRPC.exe
```
Установка Python или дополнительных библиотек не требуется.

---

## Запуск из исходного кода

### Требования
- Windows 10 / 11 (64-bit)
- Python 3.9 – 3.12

### Установка зависимостей
1. Клонируйте репозиторий:
   ```cmd
   git clone https://github.com/DilanBlue/YMusicRPC.git
   cd ymusic-discord-rpc
   ```

2. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   ```cmd
   python app.py
   ```
   *(Для работы без GUI доступен консольный скрипт: `python yandex_music_rpc.py`)*

## Самостоятельная сборка .exe

Для сборки автономного исполняемого файла используется **PyInstaller** и файл спецификации `YMusicRPC.spec`:

```cmd
pyinstaller --noconfirm YMusicRPC.spec
```

Собранный бинарник появится в папке `dist/YMusicRPC.exe`.

## Стек технологий

- **Интерфейс**: PyQt6 (кастомные виджеты, плавная анимация 60–144+ Гц, SVG-иконки, шрифты Onest и JetBrains Mono)
- **Медиа-сессии**: Windows SDK (`winsdk`) для прямого взаимодействия с System Media Transport Controls
- **Discord RPC**: `pypresence` через локальный IPC-сокет клиента Discord
- **Сборщик**: PyInstaller
