# Discord Rich Presence для Яндекс.Музыки (AMOLED Edition)

Показывает в статусе Discord, какой трек сейчас играет в Яндекс.Музыке (десктоп-приложение или сайт в браузере).

Работает на Windows 10 и 11 с использованием системного **Windows SMTC** (*System Media Transport Controls*).

---

## Возможности новой версии

- 🖤 **Чистая AMOLED тема** (100% глубокий черный цвет `#000000` без лишнего света).
- 🔘 **Переключатель активности RPC**: возможность в 1 клик включить или выключить трансляцию в Discord (при выключении статус в Discord мгновенно очищается).
- 🚀 **Надежный автозапуск**: переключатель автозапуска, адаптированный под Windows 10 и 11 через системный реестр (`HKCU\...\Run`) — работает надежно, без запросов прав администратора и стартует в свернутом виде.
- 🌐 **Интеллектуальная проверка IP и VPN**: автоматическое определение региона IP. При обнаружении зарубежного IP выводится предупреждение о необходимости раздельного туннелирования для защиты от ошибки 451 Яндекса.
- 🔽 **Сворачиваемый журнал логов (по стрелочке)**: скрываемый блок логов внизу окна для просмотра событий в реальном времени.
- 💾 **Экспорт логов**: кнопка быстрого сохранения последних 150 строк логов на Рабочий стол (`ymusic_rpc_logs.txt`).
- 📌 **Системный трей Windows**: при закрытии или сворачивании приложение продолжает работу в фоновом режиме в системном трее рядом с часами.
- 📦 **Готовый .exe**: приложение скомпилировано в автономный исполняемый файл `YMusicRPC.exe`.

---

## Запуск готового .exe

Просто запустите файл:
```
YMusicRPC.exe
```
Его можно перенести в любое удобное место или создать ярлык на рабочем столе.

---

## Запуск из исходного кода (Python)

1. Убедитесь, что установлен Python 3.9–3.12:
   ```cmd
   pip install -r requirements.txt
   ```
2. Запустите GUI-приложение:
   ```cmd
   python app.py
   ```
   *(Или `python yandex_music_rpc.py` для чистого консольного режима)*

---

## Как пересобрать .exe самостоятельно

Если вы изменили код и хотите пересобрать исполняемый файл:
```cmd
pyinstaller --noconfirm --onefile --windowed --icon=app_icon.ico --collect-all winsdk --name YMusicRPC app.py
```
Готовый файл появится в папке `dist/YMusicRPC.exe`.
